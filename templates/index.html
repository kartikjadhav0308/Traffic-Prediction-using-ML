System Architecture & Viva Presentation Workflow

Step 01

Data Ingestion

Loaded 48,120 hourly sensor records across 4 junctions from traffic.csv. Zero missing values; cleaned IDs and structured timestamps.

Step 02

Feature Engineering

Decomposed DateTime into granular cyclical time features: Hour, Day of Week, Day, Month, Year, and Weekend boolean flag.

Step 03

Dual Ensembles

Trained Random Forest (Bagging, 100 trees, max depth 15) and XGBoost (Gradient Boosting, 150 estimators, learning rate 0.08).

Step 04

Evaluation Metrics

Evaluated on unseen 20% test split. Random Forest achieved R² 0.9645 and XGBoost achieved R² 0.9534 with average MAE of ~2.5 vehicles.

Step 05

Production Serving

Deployed as a lightweight Flask web service exposing both a browser UI and a REST API (/predict) for real-time inference.
